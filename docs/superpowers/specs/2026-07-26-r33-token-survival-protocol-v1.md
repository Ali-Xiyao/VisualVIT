# R33 TIER-CXR-VLM Token Survival Protocol v1

Date frozen: 2026-07-26

Evidence class: `NON_CONFIRMATORY_TRAIN_DEV_NESTED_OOF`

## Authority and seal

- Input is restricted to the R32 v1.1 train+dev cohort.
- Eligible endpoint rows are `Stable`, `Improved`, and `Worse` only.
- Expected support: 15,698 rows and 1,874 patients.
- The 483-patient sealed VLM test, its images, labels, and metrics are forbidden.
- Gold outcomes are forbidden.

## Representation

Frozen BiomedCLIP patch tokens and finding-text embeddings are reduced to
64 dimensions by fixed outcome-free projections. Seeds 17, 29, and 43 create
three frozen hierarchical token builders. Each robust/rich sample has exactly
64 physical positions with the R32 4/12/16/16/12/4 layout.

The shared survival-probe input is a 774-dimensional summary: per token type,
64-dimensional mean, 64-dimensional max, and one logical-validity fraction.
All systems use the same probe architecture and optimizer.

## Patient folds and route nesting

Patient fold is
`int(SHA256("r33-oof-fold-v1|" + patient_id),16) mod 5`.

For every outer fold:

1. its evaluation patients are absent from every fitted model;
2. the three rich auxiliary probes for evaluation routing are fit on the other
   four folds;
3. routes for final-probe training rows are themselves generated by four
   inner patient-disjoint fits, so no row receives an in-sample route;
4. final P0-P6 probes are fit on the outer training folds and evaluated once
   on the outer fold.

## Probe training

- architecture: linear 774-to-3 classifier;
- optimizer: AdamW;
- learning rate: `1e-4`;
- weight decay: `1e-2`;
- epochs: 20 fixed;
- batch size: 128;
- inverse-class and inverse-rows-per-patient weighting;
- seeds: 17, 29, 43.

Fixed epochs avoid using an outer fold for early stopping.

## Systems

- P0: query/control token types only;
- P1: query/control plus current-state;
- P2: query/control plus global-transition;
- P3: robust fixed-64;
- P4: always-rich fixed-64;
- P5: random route with exactly matched rich coverage;
- P6: three-probe hard-consensus route;
- P7: label-reading oracle selection between P3/P4 predictions, upper bound
  only and never a trainable input.

## Shortcut controls

- Prior shuffle replaces every prior image with another patient's prior within
  the same finding. P3 and P6 are evaluated with the already fitted outer
  models.
- Query-only is P0.
- A prior-shuffle control passes if its P6-P3 delta is at least 0.5 pp lower
  than the primary delta.
- Query-only passes if P0 is at least 1.0 pp below P6.

## Primary statistics and GO

Primary endpoint:
`patient-balanced macro F1(P6) - patient-balanced macro F1(P3)`.

Use 10,000 patient-cluster paired bootstrap replicates, RNG seed 20260933,
retaining all rows and all three seed predictions for a sampled patient.

R33 GO requires all:

1. primary delta at least +2.0 pp;
2. 95% bootstrap CI lower bound above zero;
3. all three seed deltas positive;
4. P6 no more than 1.0 pp below the strongest non-oracle P0-P5 baseline;
5. prior-shuffle control passes;
6. query-only control passes;
7. exact-64, OOF, no-label-token, no-logit-token, and no-sealed-access audits
   pass;
8. 10,000/10,000 bootstrap replicates are valid;
9. if the scientific gates pass, a fresh-process reproduction is required
   before R34.

Any failure yields `STOP_R33_TOKEN_SURVIVAL`; the sealed VLM test remains
unread and R34 training is forbidden.
